# 从复现到能独立讲清楚

先按根 README 安装和运行测试。把自己的结果输出到 `reproduction/`，保留一份日志，记录 Python/依赖版本、参数、结论和没有解决的问题。参考程序已完成；下面的重点是重新获得解释能力。

## 第一步：不用势垒，检查接触

阅读 `src/negf.py`，用 `Device(height_eV=0.)` 计算零偏压透射，画出 T(E)。目标是 T≈1、R≈0；解释为什么有限器件接上无限匹配链接触后没有有限盒子的离散本征谱。

自己推导 Σ²−ξΣ+t²=0，说明为什么必须取虚部非正的支。将错误支代入一个临时副本，记录会破坏什么；完成后恢复。不要把该错误副本提交为默认实现。

## 第二步：先解释谱，再解释电流

```bash
python src/stages.py baseline --output reproduction/baseline
```

对照 `bands_transmission.png`、`iv_ndr.png` 和 `transmission.csv`。在峰值和谷值偏压下分别说明共振位置、左接触导带底、两库化学势，以及供给差的作用。不要只说“势垒变高所以电流下降”：这里电压下拉的是给定带边，共振对齐与可用纵向通道更关键。

手算一遍从横向 k 积分到 Tsu–Esaki 公式，确认自旋计数和 q³；复试应能解释为什么不能直接把一维单通道的 2q/h 积分标成 A/cm²。

## 第三步：做一次独立验证

```bash
python src/stages.py verify --output reproduction/verify
```

亲自重写单矩形势垒解析式，与 `reference.py` 的连续级联比较。然后比较 0.2/0.1/0.05 nm 谱与共振误差。写下“求解器一致”“离散逼近连续模型”“实验一致”的区别。程序只完成前两类中的指定范围。

检查 `quadrature_convergence.csv` 和 `bias_refinement.csv`。解释为什么能量积分收敛到八位数时，峰值电压仍只能按 1 mV 网格报告。

## 第四步：复现一次看似合理的错误

```bash
python src/stages.py sampling --output reproduction/sampling
```

复现相同能窗、相同步长、不同起点的谱面积差异。把 1 meV 改为 0.5/0.1/0.02 meV，自己预测误差如何变化。检查 `sampling_failure.csv`，用独立积分的面积作参考。

进一步把 5 nm 势垒改成 6 nm：先重新定位峰并估计线宽，再决定积分分点和网格，而不是直接沿用粗设置。只有做完空间、能量和参考检查后，才报告新结果。配对积分器的误差估计不是漏峰的保险。

## 第五步：提出一个有控制变量的问题

```bash
python src/stages.py sensitivity --output reproduction/sensitivity
```

三种阱宽的峰值电压怎样移动？活动区总长度也改变，电压下降规则是否构成混杂因素？自己另加一个“固定局部电场”的模型，与“固定端电压”比较，把两个问题分开表述。

温度扫描仅改变费米供给。查明真实温度效应还可能包含哪些未建模过程；不能将低温 PVR 的变化全部归因于声子散射，因为当前程序没有声子。

## 第六步：选择一个自己的实质扩展

按难度任选其一，不要求一次做完：

1. 不对称势垒：引入独立左右厚度，研究零偏压峰顶为什么可能低于 1，同时检查互易性与通量守恒。
2. 异质结质量跳变：采用守恒的变质量离散和对应连续匹配条件，重新做解析/连续验证；不能只改某一层对角元。
3. NEGF–Poisson：从接触分辨的占据谱积分空间电荷，先用平衡透明结构/电中性检查，再讨论非平衡迭代。不要一开始把电流 NDR 当作自洽收敛证据。

每次只新增一种物理，补上能区分旧/新模型的证据。自己完成的重写、发现的问题和新对照才是可以如实陈述的个人贡献。

## 复现完成的标准

能不用代码解释共振与 NDR；能自己重算一个解析参考；能复现至少一次数值失败并定位原因；能区分单位、统计、守恒、离散误差与模型误差；能说明参考代码由工具辅助完成，并清楚列出自己的工作。
